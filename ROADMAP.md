# Roadmap

These are current project priorities, not delivery promises.

- [ ] Run and publish the checked-in TCS evaluation with model, provider, retrieval, reranker, and commit details; keep answer and citation evidence scores separate.
- [ ] Compare hybrid retrieval with and without the optional cross-encoder on the same frozen question set.
- [ ] Add a privacy-safe product demo showing a PDF citation, exact text highlight, and cited figure image.
- [ ] Expand the benchmark with more documents and independently reviewed prose, table, and chart questions.
- [ ] Review authentication, authorization, resource limits, and storage isolation before supporting shared or internet-facing deployments.
- [ ] Improve arbitrary table calculations and multi-condition table filters beyond the current transaction extrema route.
